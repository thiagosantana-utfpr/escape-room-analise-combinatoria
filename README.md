# Operação Cofre Central — Escape Room de Análise Combinatória

Jogo digital educativo no estilo *Escape Room* desenvolvido para o Projeto 2 de Análise Combinatória.

## Sobre o Jogo
O jogador assume o papel de um especialista infiltrado que precisa destravar **5 cadeados digitais** (fases de dificuldade crescente) acumulando **12 chaves matemáticas** antes que o tempo de 15 minutos acabe ou que 5 alertas de erro sejam disparados.

### Estrutura das Fases
- **Fase 1 (Fácil — 1 acerto):** Princípio Fundamental da Contagem (PFC)
- **Fase 2 (Básico — 2 acertos):** Permutação Simples
- **Fase 3 (Intermediário — 2 acertos):** Permutação com Repetição e Arranjo Simples
- **Fase 4 (Avançado — 3 acertos):** Combinação Simples
- **Fase 5 (Difícil — 4 acertos):** Problemas com Restrições e Integração

## Tecnologias Utilizadas
- HTML5, CSS3 e JavaScript (Vanilla)
- Web Audio API (trilha sonora de suspense e efeitos sonoros sintetizados)
